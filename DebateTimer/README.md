# 🏛️ 高校辩论赛计时系统 · 操作说明

> 纯前端（HTML + CSS + JS）· PWA 离线可用 · 14 环节 · 双计时器 · 语音播报

---

## 一、文件结构

```
DebateTimer/
├── index.html          ← 主程序（所有界面和逻辑都在这一个文件里）
├── manifest.json       ← PWA 清单（桌面快捷方式、应用图标、窗口模式）
├── sw.js               ← Service Worker（离线缓存）
├── icons/
│   ├── icon-192.png    ← 应用图标（小）
│   ├── icon-512.png    ← 应用图标（大）
│   └── icon-maskable-512.png
└── README.md           ← 本说明
```

**整个文件夹可以随便放**（U 盘、桌面、E 盘都行），**但必须整个文件夹一起拷**——`index.html` 要能找到同目录的 `manifest.json`、`sw.js` 和 `icons/`。

## 二、直接打开（不安装）

双击 `index.html`，用 Edge / Chrome 打开即可使用。

> ⚠️ 这种方式**语音可用、计时可用**，但**没有桌面快捷方式**、**离线缓存不生效**。
> 想要完整的“应用”体验，往下看第三部分。

## 三、安装为桌面应用（推荐 ★）

### 前提

PWA 的「安装」按钮**只在 `http://` 或 `https://` 地址下出现**，直接双击 `file://` 打开不会显示安装图标。

所以需要先用一个**本地小服务器**把文件夹“发布”出来（一次性操作，1 分钟）。

### 步骤 A：起本地服务器

**方法 1（最省事，如果有 Python）**：在 `DebateTimer` 文件夹里按住 Shift + 右键 → “在此处打开 PowerShell 窗口”，输入：

```powershell
python -m http.server 8080
```

**方法 2（用 Node.js）**：

```powershell
node serve.js
```

> 本项目已附带 `serve.js`（一个 20 行的静态服务器），在 `DebateTimer` 文件夹里执行上面这句即可，比装 npx 更省事。

**方法 3（什么都不装）**：用 VS Code 的 Live Server 插件，右键 `index.html` → “Open with Live Server”。

看到命令行提示 `Serving HTTP on ...` 就成功了。

### 步骤 B：浏览器打开

地址栏输入：

```
http://localhost:8080
```

（或 Live Server 给出的地址，通常是 `http://127.0.0.1:5500`）

### 步骤 C：安装（Edge / Chrome）

**Edge：**

1. 浏览器右上角会多出一个 **⊕ 安装图标**（地址栏右侧，形状像一个小屏幕加下载箭头）
2. 点击它 → 选择「**安装**」
3. 或者：右上角 `…` → `应用` → `将此站点作为应用安装`

**Chrome：**

1. 地址栏右侧出现 **⊕ 安装图标**（一个显示器加箭头）
2. 点击 → 「**安装**」
3. 或者：右上角 `⋮` → `保存并分享` → `安装页面为应用`（部分版本显示为「安装…」）

### 步骤 D：完成

- 桌面上会出现 **「辩论计时」** 快捷方式（图标是金色表盘 + 「辩」字）
- 双击它 → **独立窗口打开，没有地址栏**，直接就是全屏计时界面
- 开始菜单 / 任务栏也能找到

## 五、操作说明

### 首页（设置）

1. 填写 **辩题**、**正方队伍**、**反方队伍**
2. 点 **「进入比赛」**
3. 顶部会固定显示这三项信息
4. 比赛中想改：点右上角 **「修改信息」**，改完再点「进入比赛」即可实时刷新

### 单边计时环节

| 按钮 | 作用 |
|---|---|
| **开始** | 播报「环节开始」→ 开始倒计时 |
| **暂停** | 暂停（再点「继续」恢复）|
| **重置** | 归零，回到待开始状态 |

**自动播报**：剩余 30 秒、剩余 10 秒各播报一次；到 0 自动停表 + 播报结束语 + **锁定**（不能再启动，需重置或切换环节）。

### 双计时器环节（第 7、12 环节）

左右两块独立计时区：

| 按钮 | 作用 |
|---|---|
| **正方开始** | 正方计时跑动，**反方强制暂停锁定** |
| **反方开始** | 反方计时跑动，**正方强制暂停锁定** |
| **暂停** | 各自暂停自己的 |
| **重置**（底部）| 双方同时归零 |

**规则**：
- 一方时间用尽 → 播报耗尽提示 → 该方**禁止再次启动**（按钮变灰）
- 只剩另一方剩余时间继续对辩
- 随时可暂停、继续

### 键盘快捷键（操作员用）

| 按键 | 作用 |
|---|---|
| `空格` | 开始 / 暂停（当前环节）|
| `R` | 重置当前环节 |
| `←` `→` | 上一环节 / 下一环节 |
| `Esc` | 退出全屏 |

## 六、语音说明

- 使用浏览器内置的**中文语音合成**（Windows 自带，不需要联网）
- 语音只在**用户点过按钮之后**才会播放（浏览器安全限制），所以第一次进入时本程序会播报「辩论赛即将开始，请辩手、评委就位」
- **音量 / 语速**由系统语音设置决定（Windows 设置 → 时间和语言 → 语音）
- 如果没声音：
  1. 检查系统音量
  2. 检查是否有中文语音包（Windows 设置 → 时间和语言 → 语音 → 添加语音 → 中文）
  3. 用 Edge 试试（Edge 的中文语音支持最好）

## 七、离线使用

- 第一次通过 `http://localhost:8080` 打开并安装后，**所有资源已缓存到本地**
- 之后即使**关掉服务器、断网**，双击桌面快捷方式照样能用
- 原理：`sw.js` 把 `index.html`、图标等全部缓存了

> 想彻底脱离“服务器”：安装成应用后，桌面快捷方式指向的是浏览器缓存的应用，**不需要再启动本地服务器**。

## 八、常见问题

**Q1：地址栏没有安装图标？**
- 确认是通过 `http://localhost` 打开的（不是 `file://`）
- Edge 需要版本 79+，Chrome 需要 73+
- 有些版本把安装入口藏在 `…` 菜单里：`应用` → `安装此站点为应用`

**Q2：双击桌面快捷方式打开后还有地址栏？**
- 那是“普通网页快捷方式”，不是 PWA 安装。请重新用上面「步骤 C」的方式安装
- 安装成功的标志：窗口没有地址栏、没有标签页，任务栏图标是应用图标

**Q3：投屏时字太小 / 太大？**
- 按 `F11` 或点右下角「全屏」按钮
- 分辨率建议 1920×1080

**Q4：语音播报打断 / 不完整？**
- 本程序在关键节点会取消上一条语音，保证提醒及时
- 如果环境太吵，调大系统音量

**Q5：换电脑怎么办？**
- 把整个 `DebateTimer` 文件夹拷过去，重新走一遍安装步骤

## 九、技术说明（给想改的人）

- `SEGMENTS` 数组定义了全部 14 个环节（秒数、类型、播报文案），改这里就能调整赛制
- `Countdown` 类负责倒计时，`state` 有 `idle / running / paused / ended` 四种
- 双计时器的切换逻辑在 `dualControl(side)` 函数
- 修改后记得**同时更新 `sw.js` 里的 `CACHE_NAME` 版本号**（如 `v1` → `v2`），否则浏览器可能仍用旧缓存
